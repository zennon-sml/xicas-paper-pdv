# XICAS PAPER PDV
Overview
XICAS PAPER PDV is a point-of-sale (POS) system designed for managing sales and storage operations efficiently with both frontend and backend integrated into a single platform.

### Technologies
- Next.js - Full-stack framework for both front and backend development.
- Database - (To be decided)
- Figma - Used for designing UI/UX and prototyping.
### Features
- User Authentication: Manage login and permissions.
- Inventory Management: Keep track of products in stock.
- Sales Management: Process sales and generate invoices.
- Dashboard: Overview of sales performance and product statistics.
